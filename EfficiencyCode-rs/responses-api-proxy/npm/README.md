# @openai/EfficiencyCode-responses-api-proxy

<p align="center"><code>npm i -g @openai/EfficiencyCode-responses-api-proxy</code> to install <code>EfficiencyCode-responses-api-proxy</code></p>

This package distributes the prebuilt [EfficiencyCode Responses API proxy binary](https://github.com/openai/EfficiencyCode/tree/main/EfficiencyCode-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/EfficiencyCode-responses-api-proxy.js --help
```

Refer to [`EfficiencyCode-rs/responses-api-proxy/README.md`](https://github.com/openai/EfficiencyCode/blob/main/EfficiencyCode-rs/responses-api-proxy/README.md) for detailed documentation.
